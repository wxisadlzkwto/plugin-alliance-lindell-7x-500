## Overview

Plugin Alliance Lindell 7X-500 emulates the Neve 1073 500-series equalizer module, capturing the warm, musical tone of the classic Neve EQ circuit beloved in recording studios worldwide.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Plugin Alliance Lindell 7X-500** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Neve 1073 Model** | Accurate recreation of 1073 transformer and amplifier circuit |
| **Three Bands** | Low shelf, parametric mid, and high shelf as in the original |
| **Harmonic Color** | Transformer saturation adds the characteristic Neve warmth |
| **500-Series Format** | Modeled on the 500-series module for compact rack use |
